### ОРБИТА 1: РАЗВЕДКА И ДЕКОМПОЗИЦИЯ — ОТЧЁТ

#### 1. Целевая аудитория (ICP)
*   **Роль:** B2B-клиенты / партнёры / лиды (L1–L3).
*   **Контекст:** Первый контакт (inbound/outbound), ожидание мгновенной ценности.
*   **Требования:** Чёткость, уважение времени, нулевой шум.

#### 2. Жёсткие ограничения (Hard Constraints)
| Параметр | Значение | Тип контроля |
| :--- | :--- | :--- |
| **Макс. длина** | **≤ 150 символов** (всего JSON-строки) | `len(json.dumps(output)) <= 150` |
| **Структура** | Строгий JSON: `greeting`, `offer`, `callToAction` | JSON Schema Validation |
| **Тон** | Дружелюбный + Деловой (Professional Friendly) | LLM-eval / Regex stop-words |
| **Контент** | 0% галлюцинаций, 0% внешних ссылок | Fact-check vs Knowledge Base |
| **Качество** | 100% орфография/пунктуация, `trim()` | Linter + Spellcheck |

#### 3. Обязательные компоненты (Decomposition)
| Поле | Функция | Оценка длины (симв.) | Риск переполнения |
| :--- | :--- | :--- | :--- |
| **`greeting`** | Идентификация бренда + приветствие | ~25–35 | Низкий |
| **`offer`** | Конкретная ценность / компетенция | ~50–70 | **Высокий** |
| **`callToAction`** | Низкостоимое действие (Low friction) | ~30–40 | Средний |
| **Оверхед JSON** | Ключи, кавычки, скобки, пробелы | **~42** | Фиксированный |

#### 4. Карта рисков (Risk Map)
| ID | Риск | Вероятность | Влияние | Митигация (Layer 1 Action) |
| :--- | :--- | :--- | :--- | :--- |
| **R-01** | **Overflow >150 chars** | **Высокая** | Блокирующее (Fail) | Жёсткий бюджет: `greeting≤30`, `offer≤65`, `cta≤35`. Использовать аббревиатуры (Б2Б, CRM). |
| **R-02** | Нарушение схемы (extra fields, types) | Низкая | Блокирующее | Генерация строго через `Pydantic`/`Zod` схему, а не свободный текст. |
| **R-03** | "Водянистое" `offer` (нет конкретики) | Средняя | Репутационное | Шаблон: `[Глагол] + [Объект] + [Результат/Срок]`. Пример: "Настроим интеграцию за 1 день". |
| **R-04** | Пассивный `callToAction` ("Напишите нам") | Средняя | Конверсия | Только активные глаголы: "Забронируйте слот", "Пришлите ТЗ", "Запустите демо". |
| **R-05** | Орфография/пробелы | Низкая | Качество | Пост-процессинг: `pymorphy2` + `strip()` + `replace('  ', ' ')`. |
